---
name: 하루약 제품 범위
description: 사용자가 지정한 갤럭시 위젯과 오프라인·원본 보존 요구사항
---

사용자는 첨부한 ‘혜진의 하루약’ HTML을 바탕으로 갤럭시 안드로이드 앱을 원한다. 실제 홈 화면 카드형 위젯이 핵심이며 기존 파스텔 디자인과 알약 아이콘을 유지한다. 작은 위젯은 완료 횟수와 다음 일정, 큰 위젯은 오늘 목록과 체크·취소를 지원한다. 로그인·서버·알람 없이 기기 안에 기록을 저장한다. 기존 HTML JSON 백업으로 일정·복용 기록·목록 순서를 복원한다.

**Why:** 사용자가 직접 명시한 제품 범위다.

**How to apply:** Expo Go나 앱 안 위젯 미리보기를 네이티브 위젯 검증으로 간주하지 않는다. APK 제작·설치·위젯 추가와 실기기 확인 경로를 제공하고, 실제 실행하지 않은 항목은 명확히 구분한다.
