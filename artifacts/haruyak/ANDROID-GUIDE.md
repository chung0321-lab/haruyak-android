# 혜진의 하루약 — 갤럭시 APK 제작·설치·위젯 확인

## 제공된 것과 아직 확인하지 못한 것

- Expo SDK 58 / React Native 0.88용 앱, `react-native-android-widget` **0.26.0** 기반 Android 네이티브 위젯, Android 빌드 스크립트가 포함되어 있습니다.
- 작은 카드: 오늘 완료 횟수, 아직 완료하지 않은 다음 일정. 시간이 있는 일정은 빠른 순서(미복용 지난 시간 포함), 시간 없는 일정은 목록 순서로 표시합니다.
- 큰 카드: 오늘 약 목록을 스크롤하여 보고 **복용 체크 / 완료·취소**를 누릅니다. 목록 개수에 따라 위젯을 길게 눌러 크기를 조절하세요.
- 앱과 두 종류 위젯 모두 기기의 **같은 SQLite 파일**을 읽고 씁니다. 앱 표시가 갱신되는 데 최대 약 2초가 걸릴 수 있습니다.
- 이 개발 환경에는 Android SDK/JDK가 없어 **APK 컴파일과 갤럭시 실기기 실행은 아직 확인하지 못했습니다.** 아래 방법으로 설치 파일을 만들어 확인합니다. 웹 미리보기나 Expo Go를 네이티브 위젯 검증으로 간주하지 않습니다.

## 방법 A: 내 PC에서 APK 만들기

1. 프로젝트 전체를 PC로 내려받습니다. `artifacts/haruyak` 폴더만 받으면 공유 설정과 잠금 파일이 빠집니다.
2. Node.js 24, pnpm 10.26.1, JDK 17 이상과 Android Studio를 설치합니다.
3. Android Studio → SDK Manager에서 프로젝트가 요구하는 SDK Platform / Build Tools / NDK를 설치합니다. 아래 사전 생성 후 `android/build.gradle`과 `android/gradle.properties` 또는 Gradle 오류가 표시하는 버전을 따릅니다. SDK 라이선스도 승인합니다.
4. `ANDROID_HOME`을 Android SDK 경로로 지정하고 프로젝트 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
bash artifacts/haruyak/scripts/build-android.sh
```

Windows는 Git Bash/WSL을 사용하거나 다음 명령을 순서대로 실행합니다.

```sh
cd artifacts/haruyak
pnpm exec expo prebuild --platform android --no-install
cd android
gradlew.bat :app:assembleRelease
```

- 스크립트 결과: 프로젝트 루트 `generated-artifacts/android/haruyak.apk`
- Gradle 직접 실행 결과: `artifacts/haruyak/android/app/build/outputs/apk/release/app-release.apk`
- `release` 빌드에 JS와 이미지가 포함되므로 설치 후 Replit, Metro, 서버 연결 없이 작동합니다.
- Expo가 생성하는 기본 개발용 서명으로 만든 **개인 기기 검증용 APK**입니다. Play Store 배포용 키는 아닙니다.
- 장기 사용 시 Android Studio의 **Generate Signed Bundle / APK → APK**로 본인 키를 만들고 안전하게 보관하세요. 같은 서명 키와 패키지 이름을 유지해야 기록을 지우지 않고 업데이트할 수 있습니다.
- 키가 달라 설치가 거절되면 **기존 앱을 삭제하기 전에 반드시 JSON 백업**하세요. 앱 삭제·데이터 지우기는 기록을 삭제합니다.

## 방법 B: GitHub에서 빌드

PC에 Android SDK를 설치하기 어렵다면 본인 GitHub 저장소로 프로젝트 전체를 옮긴 뒤:

1. **Actions → Build Galaxy APK → Run workflow**
2. 완료된 실행에서 **Artifacts → haruyak-galaxy-apk** 다운로드
3. ZIP 안의 `haruyak.apk`를 갤럭시로 옮깁니다.

구성 파일은 `.github/workflows/android-apk.yml`입니다. 이 작업은 자동 실행하지 않았으며 GitHub 계정 연결도 필요할 때 본인이 수행합니다. 별도 Expo 계정·EAS·서버는 필요하지 않습니다. GitHub 사용 한도나 비용은 본인 계정 정책을 확인하세요. 개인 복약 JSON은 저장소나 빌드 서비스에 올릴 필요가 없습니다.

## 갤럭시 설치

1. 직접 만든 APK를 휴대폰의 내 파일 → 다운로드에서 엽니다.
2. 필요한 경우 이 파일을 연 **내 파일 또는 브라우저**에 대해서만 “출처를 알 수 없는 앱 설치”를 허용합니다.
3. 삼성의 보안 차단 기능이 설치를 막으면 안내를 확인하세요. 출처와 내용을 확인한 본인 APK만 설치하고 설치 후 불필요한 허용은 되돌리세요.
4. 앱을 한 번 열고 약을 등록하거나 JSON 백업을 가져옵니다.
5. 개발 서버를 종료하고 비행기 모드에서도 앱이 열리고 기록이 유지되는지 확인합니다.

## 홈 화면 위젯 추가

1. 홈 화면 빈 공간을 길게 누릅니다.
2. **위젯**을 선택합니다.
3. **혜진의 하루약 · 작은 카드** 또는 **혜진의 하루약 · 큰 카드**를 찾습니다.
4. 홈 화면에 끌어 놓습니다. 두 종류를 동시에 추가할 수 있습니다.
5. 큰 카드는 길게 눌러 크기를 조절합니다. 약이 많으면 목록 안에서 스크롤합니다.

아이콘 바로가기나 앱 안의 위젯 미리보기가 아니라 **Android 위젯 목록에서 추가한 카드**로 확인해야 합니다. Expo Go에서는 이 위젯을 추가할 수 없습니다.

## 기존 HTML의 JSON 백업 가져오기

1. 기존 HTML 앱의 설정에서 JSON 백업을 내보냅니다.
2. 새 앱 → **위젯·백업 → 백업 가져오기**에서 해당 `.json`을 선택합니다. 직접 붙여넣기도 지원합니다.
3. 현재 데이터와 가져올 약/기록 개수를 확인한 다음 복원을 승인합니다.
4. 기존 데이터는 **교체**됩니다. 병합하지 않습니다. 필요하면 먼저 현재 앱에서 백업하세요.
5. 약의 ID, 일정 문자열, `날짜|약ID|일정` 키, ISO 복용 시각과 `약ID|일정` 목록 순서를 유지합니다. `order`가 없는 이전 백업은 약·일정 배열 순서를 사용합니다.
6. 내 약, 날짜별 기록, 오늘 목록 순서와 두 위젯을 확인합니다. 최대 파일 크기는 10MB입니다.

기록은 기기 안에만 저장됩니다. 로그인, 서버 동기화, 복약 알람은 없습니다. Android 자동 클라우드 백업은 꺼져 있습니다. JSON을 사용자가 외부 저장소로 공유하면 그 파일은 선택한 위치에 보관됩니다.

## 날짜 변경과 절전

- 날짜는 UTC가 아닌 **휴대폰의 현재 시간대**를 사용합니다.
- 내부 자정 갱신 예약, 날짜·시간·시간대 변경, 재부팅·앱 업데이트 수신, Android의 약 30분 주기 위젯 갱신을 조합합니다.
- 소리·진동·알림을 보내는 복약 알람은 없습니다. 내부 갱신은 **정확한 알람 권한을 요구하지 않는 비정확 예약**입니다.
- Android/One UI 절전, Doze, 강제 종료, 재부팅 후 잠금 해제 전에는 갱신이 지연될 수 있어 **정확히 00:00에 표시가 바뀐다고 보장하지 않습니다.**
- 위젯의 **새로고침**을 누르면 현재 날짜로 다시 읽습니다. 전날 화면이 남아 있더라도 체크는 오늘 기록으로 잘못 저장하지 않으며 이전 날짜의 위젯 버튼은 갱신만 합니다.
- 자주 지연되면 설정 → 애플리케이션 → 혜진의 하루약 → 배터리에서 제한 여부를 확인하세요. ‘절전/초절전 앱’ 목록에 있으면 제외하는 것도 도움이 됩니다. 메뉴 이름은 One UI 버전에 따라 다릅니다.
- 설정에서 **강제 종료**하면 예약이 멈출 수 있으므로 앱을 다시 여세요. 최근 앱 목록에서 밀어 닫기와 강제 종료는 다릅니다.

## 실기기 확인표

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| 작은/큰 카드 | 두 위젯을 함께 추가 | 오늘 완료 횟수·다음 일정 / 전체 오늘 목록 |
| 앱 → 위젯 | 앱에서 하나 복용 체크 | 두 위젯 횟수와 행이 갱신 |
| 위젯 → 앱 | 큰 카드에서 다른 약 체크 | 작은 카드 횟수와 앱에 반영(앱 최대 약 2초) |
| 취소 | 큰 카드 완료·취소 누르기 | 횟수 감소, 해당 복용 기록 제거 |
| 여러 카드 | 큰 카드를 두 개 추가 | 한 카드의 변경이 다른 카드에도 반영 |
| 중복 탭 | 같은 버튼 빠르게 연속 탭 | 같은 완료 의도를 적용, 의도치 않은 재취소 방지 |
| 순서 | 앱에서 목록 순서 변경 | 큰 카드에도 같은 순서 |
| 백업 | 기존 JSON 복원, 과거 날짜 선택 | 일정·기록·순서가 원본과 일치 |
| 재실행 | 앱 닫기, 다시 열기, 휴대폰 재부팅 후 잠금 해제 | 저장 기록 유지 |
| 오프라인 | APK 설치 후 비행기 모드 | 체크·취소·조회 작동 |
| 날짜 경계 | 테스트용 약을 오늘·내일 요일로 등록, 자정 대기 | 오늘 날짜/일정으로 갱신; 절전 지연 시 새로고침 |
| 시간대 | 자동 시간대 잠시 끄고 날짜가 다른 시간대 선택 후 원복 | 위젯이 새 현지 날짜 기준으로 갱신 |
| 크기/글자 | 큰 글꼴 설정, 가로·세로 크기 조절 | 목록 스크롤·버튼 접근 가능 |

날짜를 수동으로 바꿔 확인할 경우 테스트 데이터로만 수행하고 끝나면 자동 날짜·시간을 다시 켜세요. 디버깅을 위해 인증이나 숨겨진 “가짜 오늘” 기능을 넣지 않았습니다.

ADB가 있는 PC에서는:

```sh
adb install -r generated-artifacts/android/haruyak.apk
adb shell am start -n com.haruyak.hyejin/.MainActivity
adb logcat -s ReactNativeJS AndroidRuntime RNWidgetJsCommunication
```

실제 기기가 이 개발 환경에 연결되어 있지 않으므로 위 표의 갤럭시 결과는 아직 미확인입니다. 오류가 나면 모델·Android/One UI 버전·빌드 로그를 함께 확인해야 합니다.
